# Install — Aetox Security

No dependencies. This skill is a Markdown protocol — the agent reads it and follows it.

## OpenCode

```bash
skill("aetox-security")
```

Or copy `SKILL.md` (+ `references/`) to `~/.config/opencode/skills/aetox-security/`

## Claude Code

Place `SKILL.md` (+ `references/`) in your project or `~/.claude/skills/aetox-security/`.

## Other AI Tools

Varies by platform. Keep `SKILL.md` and `references/defenses.md` together — the skill loads the defenses table by that relative path. See [aetox-skills catalog](https://github.com/aetox-skills/aetox-skills).
