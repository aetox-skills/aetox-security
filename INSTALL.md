# Install — Aetox Security

No dependencies. This skill is a Markdown protocol — the agent reads it and follows it.

## OpenCode

```bash
skill("aetox-security")
```

Or copy `SKILL.md` (+ `references/`) to `~/.config/opencode/skills/aetox-security/`

## Claude Code

Place `SKILL.md` (+ `references/`) in your project or `~/.claude/skills/aetox-security/`.

## Other AI Tools

Varies by platform. Keep `SKILL.md` together with `references/defenses.md` and `references/coverage.md` — the skill loads both by those relative paths. See [aetox-skills catalog](https://github.com/aetox-skills/aetox-skills).

## Verify

```bash
ls SKILL.md references/defenses.md references/coverage.md
```
